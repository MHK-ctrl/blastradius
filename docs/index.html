150 calls per arm, in-process guard cost 28.0 µs p50 and 32.2 µs p95. Against a no-op function the percentage is meaningless; against the local tool round trip measured above it is 3.7% at p50.

Run it on your agent

from blastradius import Session, guard

@guard(effect="refund", undo=reverse_refund)
def issue_refund(customer_id, amount, *, session, idempotency_key=None):
    return payments.refund(customer_id, amount, idempotency_key=idempotency_key)

with Session(scope=["refund<=50"]) as session:
    issue_refund("cust_17", 40, session=session)

The guard forwards an idempotency_key only if your tool accepts one. In-process duplicate collapse works either way; exactly-once across processes requires the callee to honour the key.
